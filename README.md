# Water Sort Puzzle — Сортировка воды

PWA-игра: переливай воду между колбами так, чтобы каждый цвет занял ровно одну колбу (6 делений). Налить можно только в колбу с тем же цветом или в пустую; полная одноцветная колба считается зачтённой.

Сборки «чистый рандом» — партия может оказаться нерешаемой, тогда модалка «Проигрыш!» и рестарт.

## Особенности

- Единый неон-стиль (тёмная navy + циан) и светлая тема.
- Кнопка «Установить приложение» в шапке — PWA работает офлайн.
- Управление: тап по колбе-источнику, затем по приёмной (мобайл) / клик + стрелки (десктоп).

## Разработка

Vite + React, сборка с `base: './'` (подпуть GitHub Pages).

```bash
npm install
npm run dev     # локально
npm run build   # dist/ → ветка build (Pages)
```
